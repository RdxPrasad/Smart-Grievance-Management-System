# Design Standards - Smart Grievance Management System

## NEVER use:
- Purple gradients or any gaudy gradient backgrounds
- Fill-shift / gradient-animated buttons
- Fake reviews, fake testimonials, or fake metrics
- Fake hero text or generic AI marketing copy ("Revolutionize your...", "Unlock the power of...")
- Emoji icons in UI text or headings
- Em dashes (—) in copy
- Over-the-top scroll animations or parallax effects
- AI-generated stock photos or illustrations
- Cursor trail animations or decorative cursor effects
- Fake customer counters or vanity metrics ("10,000+ users!")
- Any "Made with AI" tags or badges

## Design philosophy:
- Clean, professional, minimal UI
- Real content only - no placeholder or filler text
- Subtle, purposeful animations only (e.g. fade-in on mount, hover states)
- Solid color buttons with clear hierarchy (primary, secondary, ghost)
- System or clean sans-serif fonts (Inter, Roboto, etc.)
- Neutral/professional color palette - no candy colors
- Honest copy that describes what the system actually does

## Pre-launch checklist (mandatory):
- [ ] Custom domain connected
- [ ] Favicon added
- [ ] "Made with AI" tags removed
- [ ] Privacy Policy page added
- [ ] Terms and Conditions page added

## Code quality:
- Make no mistakes - test thoroughly before presenting
- No placeholder data in production views
- All features must be functional, not decorative
